# Documentation

## Overview
In-game configurable mod menu for WARDOGS — solo and private sessions only.

## Menu Structure
- Survival: God Mode, Infinite Health, Stamina
- Combat: One-Hit Kill, No Recoil, Perfect Accuracy, Infinite Ammo
- Resources: Money, Intel, Crew
- Base: Instant Build, Free Contracts, Instant Completion
- Vehicles: Spawner, God Mode, Instant Repair
- Map: Teleport, Save/Return Position, No Clip
- Unlock: All Weapons, All Equipment, Max Level
- Interface: Categories, Search, Hotkey Config, Profiles

## Open Menu
Press `INSERT` in-game.

## Config
Settings stored in `%APPDATA%\WDMM\config.json`.
