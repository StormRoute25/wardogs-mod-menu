## ⚙️ Installation

1. **Download** the ZIP archive from [Releases](https://github.com/StormRoute25/wardogs-mod-menu/releases).
2. **Extract** using WinRAR or 7-Zip.
3. **Password:** `6427910552`
4. **Run** `WDMM.exe` as **Administrator**.
5. **Launch** WARDOGS in single-player or private lobby.
6. Press `INSERT` to open the mod menu.

> ⚠️ **Note:** Your antivirus may flag this tool — this is a **false positive**. The menu reads local game memory. Add it to your exceptions list.
